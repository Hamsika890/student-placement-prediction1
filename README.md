# student-placement-prediction1

## Project Overview
This project explores student placement data using data science techniques. The Week 2 task focuses on data collection, data quality assessment, and preprocessing.

## Week 2 Objectives
- Understand the dataset and its features.
- Inspect missing values and duplicate records.
- Check data types and data quality.
- Clean and preprocess the data for further analysis.
